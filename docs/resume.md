## 标准版（算法/AI Lab 岗，5 条）

• **端到端框架**：自建"失败挖掘 → 潜空间世界模型 CEM 纠错 → 真实仿真器同状态三臂配对回放 → 数据合成 → 微调 → 配对闭环评测"闭环，单卡 RTX 5080 完成 150 回合采矿（10 任务）、**360 个失败决策状态、1080+ 次真机配对回放**。

• **核心结论（可复现的证伪）**：在 0.5σ/维纠正预算下，世界模型纠错成功率 **13.6%** vs 不纠正 **9.4%**（**+4.2pp，exact McNemar p=0.032**）——想象确实有因果价值；但**与等预算随机扰动 14.7% 无差异（−1.1pp, p=0.61）**：价值来自"偏离策略动作"，而非世界模型选的方向。收益集中在开局（step 0：+15pp），晚期≈0（−1pp）。

• **训练侧检验**：用同一批想象纠错微调 SmolVLA（flow matching，纠错损失 3.85→0.55、专家回放损失稳定 0.04），与"同预算 replay-only"对照做 100 回合配对评测：base 61.0% / 想象数据 57.0% / 对照 58.0%（**ft_all vs ft_replay −1.0pp, p=1.0**）→ 想象数据未带来训练侧增益，把"想象无实际价值"从选择扩展到训练。

• **机理边界**：世界模型自身分数与真实增益相关性仅 **+0.09**；据此设计"定向纠错"实验（仅在可恢复的开局状态合成数据训练）。所有结论以 Wilson 区间 + exact McNemar + episode 聚合（防伪重复）呈现，并给出**工程建议**：不要为"纠错"单独支付世界模型的代价，优先用等预算重采样/扰动。

• **工程深度（可复现资产）**：精确 MuJoCo 状态序列化与回放（`none` 组逐字节复现原回合长度，锚定配对比较）；定位并修复三个使实验失效的真实问题——无约束 CEM 把低方差旋转维推到数据集极值（归一化动作目标 ×6 爆炸）→ **按维度 0.5σ 信任域**；采矿状态双重归一化；checkpoint 未随处理器管线保存。自建 8 命令 CLI（mine/imagine/verify/build/train/eval/report/diagnose/figures）+ 自动报告与图表。

## 精简版（3 条）

• 在 LIBERO 上构建"世界模型想象→失败点纠错数据"全链路（150 回合采矿 / 360 失败状态 / 1080+ 次同状态配对真机回放）：纠错 +4.2pp（p=0.032）但**与等预算随机扰动无差异**（p=0.61），训练侧亦不优于 replay-only 对照（p=1.0）。

• 提出并工具化世界模型"动作响应预检"（复现 Action Vacancy：未正则化模型动作敏感度 0.0003，敏感版 0.0215，~50×）；提出**按维度尺度信任域**的 CEM 纠错，修复归一化爆炸与双重归一化，纠错损失 3.85→0.55。

• 交付可复用工具链与统计报告（Wilson/McNemar/episode 聚合），所有数字一键重算；结论可直接指导部署取舍（纠错收益随时机衰减、离线分数不代理决策质量）。

## 工程/部署岗版本（2 条）

• 面向 VLA 部署构建可复用的"世界模型想象-验证"基础设施：8 命令 CLI、精确仿真状态回放、CEM 规划器（含按维度信任域）、数据过滤、微调与自动统计报告；单卡 16GB 消费级 GPU 全流程可复现。

• 给出可操作工程结论并量化代价：小预算纠错≈等预算随机扰动（**无需世界模型**）；大预算下随机扰动反而更差；收益集中在回合开局——把"要不要上世界模型/测试时搜索"从经验判断变成**可测量的诊断**（动作响应 + 同状态配对回放）。

## 面试防守清单（高频追问）

1. **一句话结论？** 对强策略，世界模型"想象"在测试时（选择）和训练时（纠错数据）都没有可测的优势；纠错的收益来自偏离策略动作本身，而非模型的方向。
2. **为什么 imagined ≈ random？** 0.5σ 预算下任何扰动都能把策略推出局部失败态；世界模型的"方向"在这个尺度上不携带额外信息（离线打分与真实增益相关性仅 +0.09）。
3. **那随机扰动就能修？** 小预算下可以（+4~5pp），但**大预算下随机扰动有害**（pilot：6.2% vs 不纠正 14.6%）；大偏差需要"选对方向"——这正是世界模型可能有用武之地的区域（我们诚实标注为未完成的预算扫描）。
4. **训练侧为什么没提升？** 训练数据里 2/3 是晚期不可恢复状态（纠错无效），且纠错质量仅与随机相当；已验证模型确实学会了纠错（loss 3.85→0.55），但没有可迁移到闭环的增量。
5. **`none` 组怎么"复现"原回合？** 精确 `MjSimState` 扁平化恢复 + 内部 `timestep` 对齐 + 固定 RNG；实测回放长度与原回合一致（81 步），这是配对比较成立的锚点。
6. **踩过的最深的坑？** 无约束 CEM 把旋转维（数据 σ≈0.039）推到达数据集极值 ±0.375，归一化后动作目标 ±9（策略自身动作 ±1.5），训练不稳；按维度 0.5σ 信任域后回到策略分布内。
7. **资源与可复现**：单张 16GB 消费级 GPU；`runs/main/report.md` 一键重算所有数字与图。
