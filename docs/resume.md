## 标准版（算法/AI Lab 岗，5 条）

• **端到端框架**：自建"失败挖掘 → 潜空间世界模型 CEM 纠错 → 真实仿真器同状态三臂配对回放 → 数据合成 → 微调 → 配对闭环评测"闭环，单卡 RTX 5080 完成 150 回合采矿（10 任务）、**360 个失败决策状态、1080+ 次真机配对回放**。

• **核心结论（可复现的证伪）**：在 0.5σ/维纠正预算下，世界模型纠错成功率 **13.6%** vs 不纠正 **9.4%**（**+4.2pp，exact McNemar p=0.032**）——想象确实有因果价值；但**与等预算随机扰动 14.7% 无差异（−1.1pp, p=0.61）**：价值来自"偏离策略动作"，而非世界模型选的方向。收益集中在开局（step 0：+15pp），晚期≈0（−1pp）。

• **训练侧检验（带剂量-反应的关键结果）**：用同一批想象纠错微调 SmolVLA（flow matching；纠错损失 3.85→0.55、专家回放损失稳定 0.04，证明模型确实学会了纠错），三种数据配方做 100 回合配对评测：base 61.0% / 全量想象纠错 57.0% / 同预算 replay-only 对照 58.0% / **仅"开局"纠错 45.0%（比对照低 13pp，p=0.041）**。**结论：想象数据不仅无增益，往"决策点指标最看好"的位置集中注入反而显著变差**——因为开局状态并非必然失败（策略在同一初始状态约 60-70% 成功），模仿扰动会覆盖本来正确的行为。

• **机理边界与工程结论**：世界模型自身分数与真实增益相关性仅 **+0.09**；给出可操作准则——上线世界模型前先做（a）动作响应诊断、（b）与等预算随机扰动的配对对照、（c）不要把决策点指标当训练信号。所有结论以 Wilson 区间 + exact McNemar + episode 聚合（防伪重复）呈现。

• **工程深度（可复现资产）**：精确 MuJoCo 状态序列化与回放（`none` 组逐字节复现原回合长度，锚定配对比较）；定位并修复三个使实验失效的真实问题——无约束 CEM 把低方差旋转维推到数据集极值（归一化动作目标 ×6 爆炸）→ **按维度 0.5σ 信任域**；采矿状态双重归一化；checkpoint 未随处理器管线保存。自建 8 命令 CLI（mine/imagine/verify/build/train/eval/report/diagnose/figures）+ 自动报告、图表与 CI。

## 精简版（3 条）

• 在 LIBERO 上构建"世界模型想象→失败点纠错数据"全链路（150 回合采矿 / 360 失败状态 / 1080+ 次同状态配对真机回放）：纠错 +4.2pp（p=0.032）但与**等预算随机扰动无差异**（p=0.61）；训练侧三种配方均不优于 replay-only 对照，且把纠错集中在开局会让成功率从 58% 掉到 45%（p=0.041）。

• 提出并工具化世界模型"动作响应预检"（复现 Action Vacancy：未正则化模型动作敏感度 0.0003 vs 敏感版 0.0163，~50×）；提出**按维度尺度信任域**的 CEM 纠错，修复归一化爆炸与双重归一化。

• 交付可复用工具链与统计报告（Wilson/McNemar/episode 聚合），所有数字一键重算；结论直接指导部署取舍（离线分数不代理决策质量、决策点指标不是训练信号）。

## 工程/部署岗版本（2 条）

• 面向 VLA 部署构建可复用的"世界模型想象-验证"基础设施：8 命令 CLI、精确仿真状态回放、CEM 规划器（含按维度信任域）、数据过滤、微调与自动统计报告；单卡 16GB 消费级 GPU 全流程可复现。

• 给出可操作工程结论并量化代价：小预算纠错≈等预算随机扰动（**无需世界模型**）；大预算下随机扰动反而更差；收益集中在回合开局——把"要不要上世界模型/测试时搜索"从经验判断变成**可测量的诊断**（动作响应 + 同状态配对回放）。

## 面试防守清单（高频追问）

1. **一句话结论？** 对强策略，世界模型"想象"在测试时（选择）与训练时（纠错数据）都没有可测优势；更关键的是，**决策点看起来有用的信号（+15pp 救回率）作为训练信号反而有害**。
2. **为什么 imagined ≈ random？** 0.5σ 预算下任何扰动都能把策略推出局部失败态；世界模型的"方向"在这个尺度上不携带额外信息（离线打分与真实增益相关性仅 +0.09）。
3. **为什么定向训练会更差？** 采矿单位是 episode、训练单位是 state：开局状态并非必然失败（同一初始状态约 60-70% 成功），在这些状态上模仿"扰动"会覆盖本来正确的初始行为，而每个 episode 都从这样的状态开始 → 全局退化（58%→45%，p=0.041）。
4. **那"纠错"到底有没有用？** 测试时有微弱作用（+4.2pp, p=0.032），但等价于等预算随机扰动；大偏差下需要"选对方向"（pilot：大随机扰动有害），这是世界模型可能真正有用的区域（诚实标注为未完成的预算扫描）。
5. **`none` 组怎么"复现"原回合？** 精确 `MjSimState` 扁平化恢复 + 内部 `timestep` 对齐 + 固定 RNG；实测回放长度与原回合一致（81 步），这是配对比较成立的锚点。
6. **踩过的最深的坑？** 无约束 CEM 把旋转维（数据 σ≈0.039）推到数据集极值 ±0.375，归一化后动作目标 ±9（策略自身动作 ±1.5），训练不稳；按维度 0.5σ 信任域后回到策略分布内。
7. **资源与可复现**：单张 16GB 消费级 GPU；`results/report.md` + `docs/results.md` 一键重算所有数字与图。
