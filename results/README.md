# Curated results

Small artifacts copied from `runs/main` so the headline numbers can be checked
without re-running the simulator. Everything here is regenerated by
`python -m dreamforge.report --run runs/main` (and the stage CLIs).

| file | what it is |
|---|---|
| `report.md` | full auto-generated report (verify + budget + policy eval) |
| `report_verify.png/pdf` | verify arms with Wilson CIs, imagined progress curve, score-vs-value scatter |
| `report_eval.png/pdf` | closed-loop policy comparison |
| `verify/{none,imagined,random}.jsonl` | 1080 paired replay records (360 states × 3 arms) |
| `eval_{base,ft_all,ft_replay,ft_early}.json` | per-episode closed-loop outcomes (100 episodes each) |
| `mine_summary.json` | 150-episode mining summary (base policy outcomes) |
| `imagine_summary.json` | CEM imagination summary over 360 failure states |
| `wm_diagnosis.json` | world-model action-response diagnostic (base / aso / full) |

Raw simulator states, cached frames and checkpoints are intentionally **not**
committed (`runs/` is gitignored); regenerate them with `make mine imagine`.
